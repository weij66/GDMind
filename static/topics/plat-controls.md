# 手感與物理

> 平台跳躍的命脈在「手感」。技術名詞背後是**對玩家失誤的溫柔**。

## 手感的微觀魔法

### Coyote Time（土狼時間）
角色離開平台邊緣後，仍給予 **80–150ms** 的跳躍寬限期。
玩家以為自己跳成功，但其實是設計師在背後托一把。

### Jump Buffer（預輸入）
玩家在落地前 **100ms 內**按下跳躍，系統會記住輸入，落地瞬間自動觸發。
讓「精準節奏」變成「大概節奏」。

### 加速曲線
- **起步加速**：0 → 全速 約 0.1s（短按要靈敏）
- **空中橫移**：稍弱於地面（保留下落感）
- **下落重力**：上升 1G、下降 1.6–2G（弧線更銳利、跳躍更果斷）

## 設計師的責任

```
玩家覺得「我跳得真準」
   = 設計師偷偷幫了 0.15 秒
```

這不是欺騙，是**讓玩家感受到自己的成長**。

## 經典案例

- **《超級瑪利歐》** — 重力曲線之祖
- **《Celeste》** — 公開把 coyote time、jump buffer 寫在訪談裡的良心遊戲
- **《空洞騎士》** — 空中横向控制接近完美
