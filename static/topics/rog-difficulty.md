# 難度與隨機

> Roguelike 的倫理問題：**這次死亡是「我活該」還是「運氣不好」？**

## 兩種失敗

| 失敗類型 | 玩家心情 | 設計責任 |
|---|---|---|
| 公平的難 | 「下次我能做更好」 | 努力追求 |
| 不公平的難 | 「這遊戲在針對我」 | 必須消除 |

## 隨機的設計倫理

### ✅ 好的隨機
- **影響戰術，不影響戰略** — 這場 build 的選項不同，但勝利路徑都存在
- **有 mitigation 機制** — 遇到爛開局可以重 roll 或繞路
- **可累積經驗** — 玩家學到「遇到 X 時用 Y 應對」

### ❌ 壞的隨機
- 第一層就決定生死（沒有資訊累積就被處決）
- 唯一解打不出來就 game over
- BOSS 招式隨機到「看到才反應」是不可能的

## 種子機制

每場 run 用一個 seed 決定隨機序列。
- **每日挑戰** — 全玩家同 seed，比技術
- **可分享 seed** — 「我這場太爽了你也試試」變成社群動能
- **debug 用** — 開發者重現 bug

## 經典案例

- **《Slay the Spire》** — 三選一的選擇權幾乎完美平衡了隨機與技術
- **《Hades》** — 死亡是敘事，不是失敗
- **《Spelunky》** — 純粹的「公平的難」，每次死你都知道為什麼
